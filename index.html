📘 Quick theory

Formal charge

FC = V − N − B/2. V is the atom's valence electrons as a free atom, N is the number of non-bonding (lone-pair) electrons, and B is the number of electrons shared in bonds. Example: N in NH₄⁺ has FC = 5 − 0 − 8/2 = +1.

Oxidation number

Pretend every bond is ionic. The more electronegative atom takes both bonding electrons. Bonds between identical elements are split evenly. Example: C in CH₄ is −4, C in CO₂ is +4.

Octet rule & valence

Period-2 atoms (B, C, N, O, F) have only four valence orbitals (2s + three 2p), so they can never hold more than 8 electrons. Period-3+ atoms such as P, S and Cl can show an "expanded octet" (for example SF₆ or H₂SO₄).

Wedges & dashes

A solid wedge points toward you and a hashed dash points away. Draw the narrow end at the stereocentre. A carbon with four different groups is a stereocentre, and RDKit labels it R or S using the Cahn–Ingold–Prelog priority rules.
