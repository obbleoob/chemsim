# Data sources

`data/elements.json` is generated by `tools/build_elements.py` from the sources below. Please keep this file with the data: two of the sources require attribution.

| Data | Source | Licence |
|---|---|---|
| Table layout, appearance, phase, Wikipedia summary, radii (empirical, calculated, van der Waals, metallic), Pauling electronegativity, molar heat | [Periodic-Table-JSON](https://github.com/Bowserinator/Periodic-Table-JSON) by Bowserinator, data and text from Wikipedia | CC BY-SA 3.0 |
| Atomic weights, ionization energies (all stages; from the NIST Atomic Spectra Database), electron affinities, melting/boiling points, density, lattice structure and constant, oxidation states, isotopes (masses, abundances, half-lives), discovery year/people/place, name origin, crustal and seawater abundance, uses, production ("sources"), descriptions, covalent radii (Pyykkö), Rahm radii | [mendeleev](https://github.com/lmmentel/mendeleev) v1.3.0 by Łukasz Mentel; each property's original reference is listed in its documentation | MIT |
| Emission lines (wavelength, relative intensity) of neutral atoms | NIST Atomic Spectra Database (Kramida, Ralchenko, Reader & NIST ASD Team), as mirrored in [astro-data/nist_atomic_lines_package](https://github.com/astro-data/nist_atomic_lines_package) | NIST data, cite as Kramida et al., NIST ASD |
| Flame-test colours | Standard qualitative-analysis references (compiled by hand in `js/wiki/wiki-data.js`) | — |
| Wiki articles (history, extraction, chemistry, safety) | Written for ChemSim (`data/wiki/*.json`). These are drafts and should be spot-checked. | Same as this repository |

## Caveats

- **Superheavy elements** (Z ≥ 100), **astatine** and **francium**: melting point, boiling point, density and crystal structure have never been measured. The values shown are predictions and are labelled as such in the app.
- **Emission line intensities**: NIST relative intensities come from different experiments, so they are only comparable *within one element*, and only roughly. The computed "glow colour" of an element is an estimate made from them.
- **Electron affinities** of elements that do not form stable anions (N, the noble gases, Be, Mg, …) are listed as 0 or omitted.
